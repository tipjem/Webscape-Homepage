# 프로젝트 모델: 웹스케이프 지역 사업체 WAAS 에이전시

이 문서는 바이브코딩 기반의 지역 사업체 전용 초고속 홈페이지 제작 및 관리(WAAS: Website as a Service) 비즈니스 모델 및 웹스케이프 사이트맵/라우팅 아키텍처를 정의합니다.
디자인, 색상, 타이포그래피 및 UI 룰은 상위 규칙인 `3-k-craft-floor.md` 및 `4-brand-style-guide.md`를 절대 기준으로 따릅니다.

---

## 1. 비즈니스 목적 및 타겟
- **핵심 가치:** 웹사이트가 없거나 방치된 지역 기반 사업체에 초기 구축 비용 부담을 줄이고, 지속적인 관리(WAAS)와 검색 최적화(AEO/SEO)로 실질적인 전화/상담 문의를 극대화합니다.
- **주요 타겟:** 인테리어, 청소, 이사, 방역, 설비/수리, 지역 기반 B2B 등 전화 및 상담 유치가 필수적인 사업체.
- **비즈니스 투트랙(Two-Track) 모델:**
  1. **워드프레스 브릭스(Bricks):** 완성형 템플릿 구매 및 빠른 납품.
  2. **바이브 코딩 & WAAS:** 코드 기반 초고속 자동화 구축, 쉬운 유지보수 및 월 구독형 무제한 관리.

---

## 2. 사이트맵 및 페이지 라우팅 구조 (Sitemap & Routing)

글로벌 네비게이션 바(GNB)와 모바일 바텀 시트를 통해 투트랙 비즈니스를 시각적으로 분리하여 탐색을 지원합니다:

- **`/` (Main):** 
  - 검색에 강하고 문의가 쏟아지는 매출형 홈페이지의 핵심 가치 전달.
  - 기존 웹사이트의 한계(비싼 단가, 관리 방치, 검색 미노출) 공감 섹션.
  - 투트랙 서비스 요약 및 '무료 샘플 제작' 메인 전환 CTA.
- **`/about` (About):** 
  - 에이전시 소개, '검색 최적화 × 빠른 제작 × 지속적 관리(WAAS)' 철학 안내.
- **`/services` (Service - Mega Menu):** 
  - `/services/wordpress`: 브릭스 빌더 기반 템플릿 구축 및 커스텀 안내.
  - `/services/vibecoding`: 바이브코딩 기반 고속 구축 및 WAAS 요금제(월 관리형) 상세 안내.
- **`/portfolio` (Portfolio):** 
  - 업종별(인테리어, 청소, 전문직 등) 실무 검증된 고효율 포트폴리오 및 템플릿 쇼케이스.
- **`/support` (Support):** 
  - 자주 묻는 질문(FAQ), 유지보수 범위 안내 및 고객 지원 채널.
- **`/contact` (프로젝트 문의):** 
  - 업체명, 업종, 지역, 대표 연락처 필수 입력 폼. (참고 사이트는 선택).
  - 모바일 하단에 스크롤 시 `sticky` 또는 `fixed` 상담 CTA 배치.

## 3. 기술 스택 및 개발 제약 사항 (Strict Rules)

- **Framework:** Next.js 14+ (App Router 필수)
- **Styling:** Tailwind CSS v4 (CSS Modules 금지, 테마 토큰 기반 스타일링)
- **Email Form:** Resend API 연동 (문의 폼 제출 시 관리자 이메일 `tipjem@gmail.com`으로 즉시 전송)
- **Database & Auth:** Supabase (고객 관리 및 공지사항/템플릿 연동 필요 시 활용)
- **비용 통제 (Zero AI API Cost):** 
  - 런타임에 지속적인 과금이 발생하는 유수의 AI API를 서비스 로직에 무단 연동하지 마십시오.
  - 외부 연동은 무료 API나 승인된 도구만 허용하며 과금 요소 없이 동작해야 합니다.
- **폼 에러 핸들링 UX:**
  - 문의 제출 성공/실패 여부는 토스트(Toast) 메시지 또는 접근성 높은 상태 인디케이터로 부드럽게 안내합니다.
