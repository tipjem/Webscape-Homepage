# 한국형 웹 품질 하한선 및 AI 클리셰 차단 룰 (K-Craft Floor)

이 규칙은 AI가 프론트엔드 코드를 작성하거나 수정할 때 항상 적용되는 **시각적 품질의 절대적 하한선(Floor)**입니다.

---

## 1. 62개 AI 안티패턴 (AI Slop) 원천 차단
AI가 무의식적으로 생성하는 아래의 촌스러운 패턴을 엄격히 금지합니다:

1. **보라색/시안색 네온 그라데이션 금지**:
   - 보라색(Purple/Violet) 그라데이션이나 검은 배경 위 네온 청록색(Cyan) 배색은 AI의 가장 대표적인 티입니다. 브랜드 고유의 세련된 톤을 deliberate하게 사용하세요.
2. **텍스트 그라데이션(`text-gradient`) 남용 금지**:
   - 타이틀이나 수치에 무지개색/그라데이션 텍스트를 장식적으로 넣지 마세요. 폰트의 두께, 크기, 선명한 솔리드 컬러로 위계를 표현하세요.
3. **카드 안에 또 카드 넣기 (중첩 카드 금지)**:
   - 컨테이너 안에 컨테이너, 카드 안에 카드를 중첩하지 마세요. 여백(Spacing), 얇은 구분선(Divider), 타이포그래피 크기 차이로 구조를 잡으세요.
4. **천편일률적인 동일 규격 3열 카드 그리드 금지**:
   - [아이콘 1개 + 제목 1줄 + 본문 2줄] 형태의 똑같은 카드가 3~4개 가로로 반복되는 뻔한 구조를 피하세요. 비대칭 벤토 그리드, 지그재그형, 탭형 등으로 구성하세요.
5. **무의미한 숫자 배지 및 장식용 펄스/커서 금지**:
   - "01, 02, 03" 식의 무의미한 섹션 번호, 실시간이 아닌데 깜빡이는 녹색 점(Pulsing Dot), 텍스트 커서 깜빡임 애니메이션을 넣지 마세요.
6. **유치한 바운스/탄성 애니메이션 금지**:
   - 통통 튀는 움직임 대신 자연스러운 감속 곡선(`cubic-bezier(0.16, 1, 0.3, 1)`)을 적용하세요.
7. **글래스모피즘(`backdrop-blur`) 남용 금지**:
   - 이유 없이 모든 배경을 반투명 흐림 처리하지 마세요.

## 2. 한국 웹 환경 필수 표준 (Korean Web Standards)

1. **국문 단어 단위 줄바꿈 보장**:
   ```css
   word-break: keep-all;
   overflow-wrap: break-word;
   ```
   조사나 단어가 어색하게 한 글자씩 떨어져 줄바꿈되는 현상을 방지합니다.
2. **한글 추천 폰트 스택**:
   ```css
   font-family: "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont, system-ui, Roboto, "Noto Sans KR", "Malgun Gothic", sans-serif;
   ```
   영문 전용 폰트만 지정하여 한글이 굴림체나 시스템 기본체로 깨지는 일이 없도록 합니다.
3. **국문 자간 및 행간 보정**:
   - 제목: `letter-spacing: -0.03em;`, `line-height: 1.2 ~ 1.35;`
   - 본문: `letter-spacing: -0.02em;`, `line-height: 1.6 ~ 1.75;`
4. **모바일 퍼스트 UX (가로 스크롤 제로 & 터치 타겟)**:
   - 너비 360px 모바일 화면에서 `overflow-x`로 인한 좌우 흔들림이 전혀 없어야 합니다.
   - 모든 버튼과 클릭 요소는 최소 `44px × 44px` (권장 `48px`) 이상의 터치 영역을 확보하세요.
   - `h-screen` 대신 `min-h-[100dvh]`를 사용하여 모바일 브라우저 주소창 변화에 대응하세요.
5. **자연스러운 한국어 카피라이팅 (번역투 금지)**:
   - "혁신적인", "차세대", "게임 체인저", "한 차원 높은" 같은 모호한 AI 번역투를 지양하고, 구체적인 혜택(Benefit) 중심 문구를 사용하세요.
   - 존댓말(`~하세요`, `~합니다`)을 일관성 있게 사용하세요.
6. **한국형 검색 최적화(SEO) 및 모바일 공유 썸네일 미리보기 표준**:
   - **PRD 기반 정보 매핑 원칙**: 모든 SEO 판단(지역명, 핵심 서비스, 상호명, 연락처, 대표 썸네일)은 **제공된 PRD의 정보를 절대적 기준**으로 삼아야 하며, AI가 임의로 가상의 지역이나 서비스를 지어내지 않습니다.
   - **제목 태그(Title) 필수 공식**: 상호명만 덜렁 적는 것을 엄격히 금지하며, PRD의 지역/서비스를 반영하여 반드시 `[지역명] + [핵심 서비스] | [상호명]` 공식으로 작성합니다.
   - **설명문(Description) 80자 압축 요약**: PRD의 핵심 혜택과 대표 연락처를 기반으로 80자 이내로 한눈에 보이도록 요약합니다.
   - **카카오톡/SNS 썸네일 미리보기(Open Graph) 완비**: 링크 공유 시 회색 박스 대신 세련된 대표 이미지와 안내 문구가 즉시 출력되도록 Open Graph 메타태그(`og:title`, `og:description`, `og:image`)를 필수로 작성하고 절대 URL을 지정합니다.
